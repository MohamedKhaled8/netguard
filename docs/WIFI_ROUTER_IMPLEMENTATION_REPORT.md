# Wi-Fi, Network, and Router Diagnostics Implementation Report

## 1. Architecture & Module Overview

All new functionality is integrated into the existing NetGuard AI application under `app/wifi/`, `app/ui/views/wifi_router_view.py`, and `app/ui/widgets/channel_spectrum_chart.py`, attached via `NetGuardApplication.wifi_bundle` (`app/application.py`) and mounted in `MainWindow` at `NavItem` / `QStackedWidget` index `7` (`الواي فاي والراوتر`) while preserving indices `0..6` intact.

### Implemented Modules
- `app/wifi/models.py`: Typed Pydantic contracts (`MeasurementProvenance`, `WifiInterfaceTelemetry`, `AccessPointScanResult`, `ChannelScoreBreakdown`, `BandChannelAnalysisResult`, `NetworkDiagnosticsReport`, `DnsDiagnosticsReport`, `SpeedTestReport`, `BufferbloatDiagnosticsReport`, `RouterDiscoveryResult`, `RouterConfigurationSnapshot`, `ConnectedDeviceRecord`, `RouterChangeProposal`, `UnifiedDiagnosticReport`, `BeforeAfterSnapshot`, `BeforeAfterComparison`).
- `app/wifi/coordinator.py`: `DiagnosticCoordinator` enforcing single-flight exclusive test locking across speed, bufferbloat, active RF scans, and sequential internet diagnostics, plus NetGuard meeting safety freeze checks against `TrafficController.is_critical_meeting_active()` and `hysteresis_tracker`, and explicit-approval idle QoS suspension with pre/post `ActiveStore` readback verification and guaranteed restore.
- `app/wifi/telemetry.py`: Native `wlanapi.dll` (`WlanEnumInterfaces`, `WlanQueryInterface`, `WlanGetNetworkBssList`, `WlanGetInterfaceCapability`), 802.11 Information Element parser (`parse_80211_ies`), NDIS/PHY error statistics (`Get-NetAdapterStatistics` + `WLAN_STATISTICS`), Windows operational logs (`wevtutil`), and `WifiRoamTracker`. Never derives noise floor from RSSI or invents unavailable SNR/MCS values.
- `app/wifi/scanner.py` & `app/wifi/channel_analysis.py`: Neighboring AP scanner grouped by band/channel + frequency-overlap RF congestion scoring weighting strong nearby interferers exponentially higher than distant weak beacons, handling 20/40/80/160 MHz channel bonding blocks, regulatory domains, DFS cautions, and data confidence.
- `app/wifi/network_diagnostics.py`: Sequential condition inspection (VPN, WinINET proxy, gateway drift, competing background Mbps, packet errors), 30 ICMP gateway probes, 30 ICMP `1.1.1.1` probes, IPv6 verification (`not_configured` when unroutable), and 5-hop `IcmpTracerouteEngine` run without marking silent intermediate hops as packet loss.
- `app/wifi/dns_diagnostics.py`: Multi-sample `dnspython` direct UDP/53 cache-bypass comparison across configured DNS, router DNS, `1.1.1.1`, and `8.8.8.8` with ICMP RTT baseline separation (`estimated_dns_processing_ms`), statistical variance checks, no auto DNS mutation, and meeting freeze enforcement.
- `app/wifi/speed_test.py` & `app/wifi/bufferbloat_diagnostics.py`: Multi-stream HTTPS speed measurement distinguishing Wi-Fi PHY rate vs local LAN (`unavailable` without LAN endpoint) vs actual Internet download/upload throughput + QoS state; sequential Idle -> Download Load -> Drain Pause -> Upload Load -> Optional Combined Load bufferbloat grading.
- `app/wifi/router/` & `app/wifi/device_management.py`: Local-only RFC1918/gateway origin validation, HTTP/untrusted TLS security warnings, Session-only & Windows `CredWriteW` storage, `redact_secrets` sanitizer, passive HTTP + UPnP IGD discovery, modular `zte` / `huawei` / `tplink` / `generic_probe` adapters (explicitly marked `hardware_verified=False` until physically tested with credentials), safe backup + readback verify + rollback write flow, and merged OS ARP + router connected device list with honest limitation notices.
- `app/wifi/recommendations.py` & `app/wifi/reporting.py`: Unified cross-layer fault ranking across all 8 fault domains, SQLite `wifi_diagnostic_snapshots` persistence, Before/After condition-drift and noise-threshold evaluation, and redacted JSON/HTML exports.
- `app/ui/views/wifi_router_view.py` & `app/ui/widgets/channel_spectrum_chart.py`: Complete 8-tab dark-surface RTL workstation view integrated with `MainWindow`, `tokens.py`, `ui_wiring.csv`, and `check_layout.py`.
